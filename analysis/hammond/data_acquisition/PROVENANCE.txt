  Hammond2019_microglia_AllSamples_annotated.h5ad  (main product)
      The object above after clean-up: the "X" prefix that R added to
      gene names removed (original names kept in var['symbol_original']),
      cell_type_paper column added, provenance embedded in
      uns['provenance'], UMAP coordinates added in obsm['X_umap'].
      X        = log-normalized expression.
      layers['counts'] = raw UMI counts (merged from GEO GSE121654).
      Check: the raw-count sum of every cell == obs['nCount_RNA']
      (exact match).

  Hammond2019_microglia_cell_metadata.csv
      Metadata of the 76,149 cells: Paper_Cluster / cell_type_paper
      (the 14 clusters of the paper), Age, Sex, Condition, Batch, GEO
      number, t-SNE coordinates.

  Hammond2019_microglia_clusterMean_expression.csv
      Mean log-normalized expression, Paper_Cluster (14) x genes (20,579).

  Hammond2019_microglia_cluster_counts.csv
      Number of cells per cluster.

----------------------------------------------------------------
[Notes]
----------------------------------------------------------------
  - The expression in X is log-normalized (Seurat LogNormalize). Raw
    counts are in layers['counts'] (from GEO GSE121654).
  - Cluster definitions of the paper (Paper_Cluster): the 14 clusters
    1, 2a, 2b, 2c, 3, 4, 5, 6, 7a, 7b, 7c, 8, 9, Mono/Mac.
  - The expression of all 76,149 cells x 20,579 genes would take
    several GB as one CSV, so it is kept in the h5ad; only the cluster
    means are written as CSV.
